В процессе правок

Меняем маленькими шагами: 1 задача = 1 коммит.

Не трогаем data/volumes, если задача про фронт. Никаких правок в docker/volumes/* руками.

После каждого маленького патча

Проверка на сервере

/scan/?code=... открывается и показывает карточку

/instruction/?id=... (или как у вас устроено) открывается

wp-json/vp/v1/lookup?code=... отвечает 200

Команды для быстрых smoke-тестов (без браузера):

DOMAIN="https://xn--b1awacccnl0jqa.xn--p1ai"
CODE="VP-PH-EP2231-START"  # подставь реальный


curl -sS -i "$DOMAIN/scan/?code=$CODE" | head -n 20
curl -sS -i "$DOMAIN/wp-json/vp/v1/lookup?code=$CODE" | head -n 40

Коммит + пуш

git add -A
git commit -m "scan: QR click -> /scan?code= + WebShare button"
git push -u origin fix/scan-qr-share
Откат (если что-то пошло не так)

Откат последнего коммита:

git revert HEAD
git push

Или временно вернуться на main:

git checkout main
git pull --rebase
